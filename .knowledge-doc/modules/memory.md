# 记忆管理模块

## 概述

记忆管理模块负责管理对话历史和上下文压缩，通过三层记忆架构解决长上下文带来的 Token 爆炸和遗忘问题，实现记忆的高信息密度管理。

## 组件

### MemoryManager
- **位置**: [memory.py](../../src/deepseek_code/memory.py)
- **用途**: 管理对话历史和上下文压缩
- **关键类**: `MemoryManager`

### 三层记忆架构

#### 1. 工作记忆 (Working Memory)
- **存储**: 当前 Ralph 循环的完整对话列表（内存）
- **用途**: 保持操作的精确性
- **特点**: 
  - 完整的历史记录
  - 实时更新
  - 不经过压缩

#### 2. 近期记忆 (Recent Memory)
- **存储**: 结构化摘要 + 滑动窗口
- **用途**: 作为上下文缓冲区
- **特点**: 
  - 由压缩器生成
  - 高信息密度
  - 滑动窗口机制

#### 3. 长期记忆 (Long Term Memory)
- **存储**: 跨会话的持久化知识
- **用途**: 项目规范和经验复用
- **特点**: 
  - 项目规范文件 (DEEPSEEK.md)
  - 未来支持向量数据库
  - 语义检索

### Token 预算驱动
- **参数**: `max_context_tokens`（默认 8000）
- **触发机制**: 当上下文用量达到模型最大窗口的 80% 时，异步触发压缩
- **预算分配**:
  - System Prompt: 固定预算
  - 结构化摘要: 100 tokens
  - 滑动窗口: 剩余预算

### 压缩方法
- **双阶段"蒸馏"**:
  1. 提取关键信息（动作、文件变更、错误）
  2. 生成结构化 JSON 摘要
- **保留内容**:
  - 关键决策
  - 文件变更
  - 错误信息
  - 下一步行动
- **掩码优化**: 对早期冗余的工具输出用占位符替换

### 上下文组装
- **方法**: `build_messages()`
- **组装顺序**:
  1. System Prompt（系统提示）
  2. 项目规范（长期记忆）
  3. 结构化摘要（近期记忆）
  4. 滑动窗口内最近 K 轮对话（工作记忆）
  5. 当前 Ticket（任务描述）

### 系统提示
- **方法**: `_build_system_prompt()`
- **内容**:
  - 身份定义（DeepSeek Code AI 助手）
  - 工作流程（Ralph 循环四阶段）
  - 工具使用说明
  - 输出格式要求
- **特点**: 
  - 明确的工作流程指导
  - 工具调用规范
  - 错误处理策略

### 历史裁剪
- **方法**: `_trim_history()`
- **策略**:
  1. 计算当前 Token 数量
  2. 从最新消息开始保留
  3. 达到预算时停止
  4. 对裁剪部分生成摘要
  5. 将摘要插入到保留部分之前
- **摘要内容**:
  - `actions_taken`: 最近 10 个动作
  - `files_modified`: 修改的文件列表
  - `errors_encountered`: 最近 5 个错误
  - `note`: 早期对话已裁剪（如果无其他信息）

### Token 估算
- **方法**: `_estimate_tokens()`
- **策略**: 简单估算（字符数 / 2）
- **用途**: 快速判断是否需要压缩

### 消息管理
- **方法**:
  - `load_ticket()`: 加载 Ticket 描述到历史
  - `append_assistant()`: 添加助手回复
  - `append_tool_result()`: 添加工具执行结果
  - `append_system()`: 添加系统消息
  - `clear_working()`: 清空工作记忆

### 摘要生成
- **方法**: `_summarize_history()`
- **提取内容**:
  - 工具执行结果（识别写入、补丁应用）
  - 错误信息（命令失败、Error、错误）
  - 其他动作（截断到 100 字符）
- **输出格式**: JSON 结构化摘要

## 使用示例

### 基本使用
```python
memory = MemoryManager(max_context_tokens=8000)
memory.load_ticket(ticket)
memory.append_assistant("思考内容")
memory.append_tool_result("工具执行结果")
messages = memory.build_messages()
```

### 系统消息注入
```python
memory.append_system("进度检查提醒")
```

### 清空记忆
```python
memory.clear_working()
```
